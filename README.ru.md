# Collector → Lazer

[English](README.md) · **Русский**

Ставит коллекции с [osucollector.com](https://osucollector.com) в **osu!lazer** — но только нужные звёзды.

Коллекция на 10 000 диффов от 4★ до 8★, а нужны только 7–8★? Отметь два столбца и нажми одну кнопку. Приложение скачает сеты, вырежет из них все остальные сложности и передаст их в запущенный osu!lazer. Саму коллекцию потом добавляет один проход мастера настройки lazer.

## Скачать

Последняя версия: **[Releases](https://github.com/X4vi3/osu-collector-lazer/releases/latest)** (Windows 10/11 x64).

- `…_x64-setup.exe` — установщик, обновляется прямо из приложения.
- `Collector-to-Lazer-portable.exe` — без установки, просто запустить. Новые версии скачиваются вручную.

Windows SmartScreen может предупредить о неизвестном издателе: приложение не подписано (подпись стоит денег). Нажми **Подробнее → Выполнить в любом случае**.

## Как пользоваться

1. Вставь ссылку на коллекцию (`https://osucollector.com/collections/12345/…`) или просто её номер. Можно и перетащить файл `collection.db`.
2. Отметь нужные столбцы звёзд. Сразу видно, сколько это диффов и сетов и сколько из них уже есть в osu!lazer.
3. Нажми **«Скачать и установить в Lazer»**, osu!lazer держи открытым.
4. В конце выполни три шага с экрана: в lazer открой **Настройки → Общие → Run setup wizard → Импорт**, выбери папку, которую покажет приложение, оставь только **Коллекции** и импортируй.

Коллекции копятся в этой папке: можно поставить несколько и пройти мастер один раз в конце. Повторный импорт безопасен — lazer сливает коллекции по имени и не дублирует карты.

## Что приложение делает с игрой

- **Никогда не пишет в базу lazer** (`client.realm`). Карты попадают через штатный импорт lazer (как двойной клик по `.osz`), коллекции — через штатный мастер.
- **Читает** файлы карт lazer (только чтение), чтобы не качать то, что уже стоит. Отключается в настройках.
- lazer при повторном импорте заменяет сет целиком. Приложение это учитывает: уже стоящие сложности сета кладутся в новый архив, так что ничего не пропадает.
- Оставшиеся сложности копируются побайтно, поэтому lazer узнаёт их в коллекции.

## Откуда карты

Сеты качаются с публичных зеркал — [osu.direct](https://osu.direct), [catboy.best](https://catboy.best), [sayobot](https://osu.sayobot.cn), [nerinyan](https://nerinyan.moe) — с нескольких сразу и с соблюдением их лимитов. Видео не скачивается.

Проект неофициальный и не связан с osu!, osu!collector или зеркалами. Если нравится osu!collector, их можно поддержать [их клиентом](https://osucollector.com/client).

## Сборка из исходников

Нужны Node.js 20+, Rust (stable, MSVC), Visual Studio Build Tools, WebView2.

```powershell
npm ci
npm run tauri dev       # запуск в режиме разработки
npm run tauri build     # установщик и exe в src-tauri/target/release
cargo test --manifest-path src-tauri/Cargo.toml
```

`npm run dev` / `npm run build` / `npm test` делают то же через `scripts/env.ps1`, который умеет использовать локальный тулчейн из `.tools/`.

### Выпуск версии

`scripts/release.ps1 0.2.0` поднимает версию, ставит тег и пушит; GitHub Actions собирает установщик, portable-exe и подписанный манифест обновлений. В репозитории нужен секрет `TAURI_SIGNING_PRIVATE_KEY` (ключ подписи обновлений).
